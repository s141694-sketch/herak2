## كيف تفحص بنفسك

```bash
cd spike && npm install
npm run server   # نافذة أولى
npm run dev      # نافذة ثانية، ثم افتح http://localhost:5173/?doc=test&user=مازن
```
افتح الرابط نفسه في نافذتين بمستخدمين مختلفين للتحرير المتزامن، أو أضف `&mode=blocks` لوضع الكتل.
