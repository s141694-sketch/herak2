# حراك 2 — تشغيله في GitHub Codespaces ليجرّبه زملاؤك

| البند | القيمة |
|---|---|
| التاريخ | 2026-10-09 |
| لمن | المالك. لا يلزم تثبيت أي شيء على جهازك |
| القرار | D99 |
| ما ليس هو | ليس خادمًا دائمًا. يعمل ما دامت جلسة Codespace مفتوحة، فيناسب جلسات تجربة مع زملائك |

**الفكرة:** يعطيك GitHub جهازًا في السحابة تفتحه من المتصفح، اسمه Codespace. نشغّل فيه حراك بأمر واحد، فيعطيك GitHub رابطًا عامًّا يفتحه زملاؤك من أجهزتهم.

## 1. افتح Codespace (مرة واحدة)

0. **قبل إنشائه:** GitHub ← صورتك أعلى اليمين ← **Settings** ← **Codespaces** ← **Default idle timeout**: اكتب `240` واحفظ. هذا الإعداد يسري على ما تنشئه بعده فقط، فإن كان لك Codespace قبله فأنشئ جديدًا.
1. افتح صفحة المشروع: https://github.com/s141694-sketch/herak2
2. أعلى يسار قائمة الملفات، زر اسم الفرع (يكتب `main` أو غيره): اختر **`claude/phase-0-spike`**.
3. اضغط الزر الأخضر **Code**، ثم تبويب **Codespaces**، ثم **Create codespace on claude/phase-0-spike**.
4. تنفتح صفحة تشبه برنامج تحرير (VS Code) في المتصفح. انتظر حتى تكتمل، دقيقتين إلى خمس دقائق أول مرة.
5. أسفل الصفحة لوحة اسمها **TERMINAL**. إن لم تظهر: القائمة ☰ ← **Terminal** ← **New Terminal**.

## 2. شغّل حراك

اكتب في TERMINAL ثم اضغط Enter:

```sh
infra/codespace.sh start
```

- أول مرة يأخذ 10 إلى 20 دقيقة: يبني حراك. اترك الصفحة مفتوحة.
- في النهاية يطبع: `Harak is at: https://...app.github.dev`. هذا رابط حراك.
- إن طبع جملة تبدأ بـ «Make the address reachable»: افتح تبويب **PORTS** بجانب TERMINAL، واضغط بالزر الأيمن على المنفذ **8000 (Harak)**، ثم **Port Visibility** ← **Public**. بدون ذلك لا يفتح الرابط إلا لك.

## 3. الحسابات

**الأسرع، حسابات جاهزة لكل دور:**

```sh
infra/codespace.sh demo
```

يطبع أربعة حسابات، لكل حساب كلمة مرور خاصة به صُنعت لهذا الـ Codespace وحده. تُصنع مرة واحدة: إعادة الأمر تطبعها كما هي ولا تمحو شيئًا مما جرّبتموه.

| الحساب | الدور |
|---|---|
| `multi@example.com` | مدير التدريب |
| `author@example.com` | مؤلف |
| `reviewer@example.com` | مراجع |
| `approver@example.com` | معتمِد |

أرسل لكل زميل الرابط، وحسابه وكلمة مروره وحدها. من يملك كلمة مرور حساب المدير يتحكم في مؤسسة التجربة، فاحتفظ بها لنفسك.

**أو مؤسسة فارغة** تبدأ بها كما سيبدأ العميل:

```sh
ORG_NAME="مركز التجربة" ORG_SLUG=center ADMIN_EMAIL=you@example.com infra/codespace.sh organization
```

يطبع رابطًا تختار منه كلمة مرور المدير. ثم تدعو زملاءك من صفحة **الأعضاء**. البريد لا يُرسل من Codespace، فاطبع رابط كل زميل وأرسله له بنفسك:

```sh
infra/codespace.sh link colleague@example.com center
```

حيث `center` المعرّف القصير للمؤسسة. ولقراءة الرسائل التي كان حراك سيرسلها، بروابطها: `infra/codespace.sh emails`.

## 4. أثناء التجربة

- **زملاؤك:** يفتحون الرابط. قد يعرض GitHub صفحة تنبيه قبل حراك، فيضغطون **Continue**. ثم صفحة دخول حراك.
- **ما تجرّبونه:** السيناريو في `docs/2026-10-08-harak2-local-trial.md`، القسم 3.
- **طوال الجلسة شغّل في TERMINAL:**

  ```sh
  infra/codespace.sh watch
  ```

  يطبع سطرًا مع كل زيارة لحراك. يعدّ GitHub ذلك نشاطًا، فلا يتوقف الـ Codespace. أما فتح الصفحة وحده فلا يُعدّ نشاطًا، فيتوقف بعد مهلة الخطوة 0 من القسم 1 (30 دقيقة إن لم تغيّرها). لإنهاء المراقبة: Ctrl+C، وحراك يبقى يعمل.
- **12 ساعة على الأكثر:** يتوقف الـ Codespace بعدها مهما كان النشاط.
- **إن توقف أو أعدت فتحه:** شغّل `infra/codespace.sh start` من جديد، فقد يعود المنفذ خاصًا لا يفتح إلا لك.

## 5. بعد التجربة

| ما تريد | ماذا تفعل |
|---|---|
| إيقاف حراك وحفظ بياناته | `infra/codespace.sh stop`، ثم من https://github.com/codespaces اضغط ⋯ بجانب الـ Codespace ← **Stop codespace**. الإيقاف يوفّر ساعاتك المجانية |
| تشغيله مرة أخرى | افتح الـ Codespace من https://github.com/codespaces، ثم `infra/codespace.sh start`. يبدأ في دقيقة أو اثنتين، والرابط والبيانات كما هي |
| الرسائل التي كان سيرسلها | `infra/codespace.sh emails` |
| انتهيت من التجارب كلها | احذف الـ Codespace من https://github.com/codespaces (⋯ ← **Delete**)، فالمتوقف يشغل مساحة من حصتك |

## 6. حدود

- **حصة مجانية محدودة:** حساب GitHub المجاني يعطي 120 «ساعة نواة» شهريًا، أي نحو 60 ساعة تشغيل لهذا الجهاز (نواتان)، و15 غيغابايت-شهر مساحة. الـ Codespace المتوقف لا يستهلك ساعات، لكنه يستهلك المساحة (حراك وصوره كبيرة). الحساب الطلابي قد يعطي أكثر، ولم أتحقق من ذلك. تابع استهلاكك في https://github.com/settings/billing.
- **عنوان كل زائر:** يأخذه حراك من آخر عنوان يضيفه وسيط GitHub، إن أضافه. لم أتحقق من ذلك داخل Codespace حقيقي، فقد يرى حراك كل زملائك عنوانًا واحدًا. لذلك رُفع حد محاولات الدخول هنا إلى 60 في الدقيقة، ويبقى إيقاف الحساب بعد كلمات المرور الخاطئة يحمي كل حساب.
- **ليس دائمًا:** يتوقف إذا تُرك بلا نشاط. والـ Codespace المتوقف يُحذف بعد 30 يومًا بلا استعمال (إعداد GitHub الافتراضي)، ومعه بياناته.
- **الرابط** ثابت ما دام الـ Codespace نفسه. إن أنشأت Codespace جديدًا تغيّر الرابط وبدأت البيانات من الصفر.
- **لا بيانات حقيقية:** محتوى تجريبي فقط حتى تُحسم المسألتان القانونيتان (D94).
- **ما جُرّب:** CI يشغّل الأمر على لينكس، ويرسل الطلبات كما نفترض أن يرسلها وسيط GitHub (عنوان محلي، بلا https). يتحقق من: الصفحة، والواجهة البرمجية، وفتح اتصال التحرير الحي (101)، والدخول من العنوان العام، وكلمات مرور الحسابات، والرسائل مقروءة بروابطها، وتنزيل ملف. **لم يُجرَّب داخل Codespace حقيقي،** وما يرسله وسيط GitHub افتراض لا مشاهدة. أول تشغيل عندك هو التجربة الحقيقية، فأرسل لي أي خطأ يظهر كما هو.
