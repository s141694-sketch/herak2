## 1. ما يُبنى

```
الصفوف (عقد، كتل، روابط، كفايات مستهدفة)
   │
   ├─ طبقة القواعد (Python، دائمًا)  ──► Findings مصدرها rule
   │     قواعد حراك 1 منقولة بتطابق كامل + قواعد حراك 2 (الروابط، تغطية الكفايات)
   │
   └─ طبقة الذكاء الاصطناعي (حيث تعجز القواعد فقط) ──► Findings مصدرها ai
         بوابة واحدة: مزوّد قابل للتبديل، JSON بمخطط، إعادة محاولة، تخزين ببصمة المحتوى،
         سجل AIUsage، حصة شهرية، وضع «قواعد فقط»
   │
   ▼
QualityReport لكل نسخة ← Findings ← تجميع صعودًا على الشجرة ← تجاهل بسبب
```

- **حراك 1 لا يُعدَّل أبدًا.** `parity/` يشغّله في متصفح آلي ويستدعي دواله النقية نفسها على مجموعة نصوص ثابتة، ويحفظ نتائجه في `parity/expected/`. اختبارات Python تقارن مخرجات القواعد المنقولة بهذه النتائج حرفيًا.
- **الذكاء الاصطناعي يقترح فقط.** كل نتيجة تحمل تفسيرًا وثقة ومصدرًا، والرد غير المطابق للمخطط يُرفض ولا يصل إلى المستخدم. اقتراحات الصياغة والاستيراد لا تُطبَّق إلا بقبول المؤلف.
- **بوابة الإطلاق (المواصفة 5.5):** لا يعمل أي وكيل لمؤسسة إلا بعد تسجيل نتيجة تقييم على المجموعة الذهبية تتجاوز حد المالك لذلك الوكيل ونسخة تعليماته ونموذجه. حتى يحدد المالك الحدود ويبني الخبراء المجموعة الذهبية، يعمل المنتج بالقواعد فقط.
